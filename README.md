Un Árbol AVL es mejor que un BST normal para un ranking académico porque se mantiene balanceado automáticamente.  
Esto evita que el árbol quede desordenado o muy cargado hacia un solo lado al insertar estudiantes.   Gracias a ese balance, las búsquedas por skill_score y el recorrido del ranking son más eficientes.   

En este programa el AVL permite ordenar a los estudiantes por skill_score de forma más rápida y organizada.   Además, si dos estudiantes tienen el mismo score, se usa el student_id como desempate.
